Nambli 1.003 — Google Fonts design review candidate, 2026-10-10

Twelve TTF and twelve WOFF2 faces built from sources/ufos.
Both builds produced identical SHA-256 values; see
documentation/visual-quality-1.003/build-validation.json.

Added overshoot from 1.002 is removed, contour smoothing is retained, and
only the side carons in Ľ, ľ, ď, ť and uni030C.alt are modestly strengthened.
Other accent designs are retained. See documentation/VISUAL-QUALITY-1.003.txt.

Nambli-1.003-review.zip packages these 24 fonts, OFL.txt, this README and
SHA256SUMS.txt. Editable UFO sources and build instructions are available
on the same Git branch under sources/ufos and sources/BUILDING.md:
https://github.com/Tor-Production/nambli-font/tree/codex/fix/visual-quality-candidate

This candidate is published for design review. It is not the stable release,
not a Google Fonts acceptance, and not an official package QA pass.
OFL.txt accompanies these files.
